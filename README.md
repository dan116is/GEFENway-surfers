# 🛼 גפן ווי סרפרס

## מה שונה כאן מ-Subway Surfers

| Subway Surfers | גפן ווי סרפרס |
|---|---|
| מתנגשים → המשחק נגמר | מתנגשים → מעידה קטנה, ממשיכים. **אין הפסד ואין "Game Over"** |
| מהירות מטפסת עד שנכשלים | מהירות עולה לאט ונעצרת בתקרה שאתם קובעים |
| המשחק לא נגמר לבד → מריבה על הכיבוי | **השמש שוקעת לאט** והדמות מגיעה לבית העץ — סוף רגוע ומתוכנן |
| קניות בתוך האפליקציה, פרסומות, מטבעות אמיתיים | אפס פרסומות, אפס קניות, אפס רשת. הכל אופליין |
| טקסט וממשק לקוראים | ממשק ללא קריאה: אייקונים, צבעים וקול בעברית |
| דמויות נעולות מאחורי מטבעות | **כל 12 הדמויות פתוחות תמיד**, ובוחרים מחדש לפני כל סיבוב |
| חשבון אחד למכשיר | **כמה שחקנים** — לכל ילד שם, צבע, דמות, כוכבים והגדרות משלו |
| דיוק אצבע גבוה | שליש מסך שלם לכל פעולה + זיהוי החלקה סלחני |

### שחקנים 👥
המשחק תומך בכמה ילדים על אותו מכשיר. במסך הפתיחה מופיע **"מי משחק?"** עם
כרטיס לכל ילד (הדמות שלו רצה בכרטיס) — מקישים ומשחקים. לכל שחקן נשמרים בנפרד
השם, הצבע, הדמות, הכוכבים, אורך הסשן, המהירות והסטטיסטיקה. הוספה ומחיקה של
שחקנים נמצאות בהגדרות ההורים.

### הדמויות 🐾
שתים־עשרה דמויות, כולן פתוחות מהרגע הראשון וכולן זמינות לכל שחקן:

| | | |
|---|---|---|
| 🦊 שועלי | 🐰 שפנפנה | 🐱 חתולי |
| 👑 נסיכונת | 🐧 פינגי | 🧚 פיונה |
| 🦌 עופרי | 🦕 דינו | 🦄 חדקורן |
| 🐼 פנדי | 🐯 טיגי | 🤖 רובי |

כל דמות מצוירת בקוד מנתונים — אוזניים, שיער, כתר, כנפיים, קרן, חצאית, פרפר,
פרחים וקרניים הם שדות ברשומת הדמות, ולא ציור ידני לכל אחת.

### שער הצבעים 🌈
מדי כמה זמן מופיע שער עם שלוש קשתות בצבעים שונים, ומתבקשים לעבור בצבע מסוים
(גם בכתב, גם בקול, גם בעיגול צבע גדול). זה לימוד צבעים שמשתלב בתוך הריצה
במקום להפריע לה. אפשר לכבות בהגדרות ההורים.

## התקנה על האייפון (בלי App Store, בלי מק, בלי תשלום)

1. מעלים את התיקייה לאירוח סטטי כלשהו. הכי פשוט — **GitHub Pages**:
   בריפו הזה → `Settings` → `Pages` → תחת *Build and deployment* בוחרים
   **GitHub Actions**. ה-workflow שבתיקייה `.github/workflows` ירוץ אוטומטית
   על הענף הראשי (או ידנית מלשונית *Actions* → *Deploy to GitHub Pages* →
   *Run workflow*). מקבלים כתובת בסגנון
   `https://dan116is.github.io/GEFENway-surfers/`.

   חלופה בלי Actions: באותו מסך בוחרים *Deploy from a branch*, הענף הרצוי
   ותיקיית `/ (root)`.
2. פותחים את הכתובת ב-**Safari** באייפון (חייב Safari — לא כרום).
3. כפתור השיתוף ⬆️ → **הוספה למסך הבית** → **הוסף**.
4. סוגרים את Safari ופותחים את האייקון מהמסך. המשחק נפתח במסך מלא, בלי סרגלי
   דפדפן, ועובד גם במצב טיסה.

> טיפ: אחרי הפתיחה הראשונה כל הקבצים נשמרים במכשיר (Service Worker),
> אז אין צורך באינטרנט בכלל.

> טיפ שני, שווה זהב עם ילד בן 4: **הגדרות → נגישות → גישה מודרכת**
> (Guided Access). מפעילים, ואז שלוש לחיצות על כפתור הצד נועלות את האייפון
> על המשחק בלבד — אי אפשר לצאת בטעות לאפליקציות אחרות או להתקשר לסבתא.

### לרוץ מקומית

python3 -m http.server 8000
# ואז http://localhost:8000

### לעטוף כאפליקציה נייטיב (אופציונלי)
מי שיש לו מק + Xcode יכול לעטוף את אותה תיקייה:
```bash
npm i -D @capacitor/cli @capacitor/core @capacitor/ios
npx cap init "גפן ווי סרפרס" com.gefen.surfers --web-dir=.
npx cap add ios && npx cap open ios
```
להתקנה על מכשיר אישי מספיק Apple ID חינמי (החתימה תקפה 7 ימים);
תעודת מפתח בתשלום נדרשת רק להפצה.

## הגדרות הורים

לוחצים **לחיצה ארוכה** (כשנייה וחצי) על גלגל השיניים ⚙️ במסך הבית — עיגול
צהוב מתמלא סביבו ואז נפתחות ההגדרות. ילד בן 4 לא נשאר לחוץ מספיק זמן בטעות.

| הגדרה | מה זה עושה |
|---|---|
| שם השחקן | מופיע במסך הבית, בסיום ובעידוד הקולי |
| צבע אהוב | צבע החולצה של הדמות ושל הגלגיליות |
| אורך סשן | 5 / 10 / 15 דקות או בלי הגבלה. **זה גם טיימר מסך רך** |
| מהירות | רגוע / רגיל / מהיר — משפיע על מהירות ההתחלה ועל התקרה |
| צלילים | כל הצלילים מסונתזים בקוד, אין קבצי אודיו |
| עידוד בקול | קול עברי של המכשיר. אם אין קול עברי מותקן — פשוט שותק |
| שערי צבעים | הפעלה/כיבוי של רכיב הלימוד |
| רעידות מסך | לכיבוי אם זה מפריע |
| בחירת דמות לפני כל סיבוב | אם מכבים — הכפתור הירוק מתחיל ישר עם הדמות האחרונה |
| איכות תצוגה | רגיל / גבוה / מקסימלי — ראו למטה |
| שחקנים | הוספה ומחיקה של ילדים, כולל הכוכבים והסטטיסטיקה שלהם |

בתחתית המסך יש גם סטטיסטיקה: כמה סבבים, כמה זמן משחק בסך הכל וכמה שערים.

## איך משחקים

לפני כל סיבוב נפתח מסך **"מי רץ היום?"** — שתים־עשרה דמויות פתוחות, מקישים על אחת
(היא מתחילה לרוץ בכרטיס) ובוחרים צבע חולצה, ואז כפתור ירוק גדול "קדימה!".
אפשר לכבות את המסך הזה בהגדרות ההורים אם עדיף להתחיל ישר.


- **נגיעה בשליש השמאלי / הימני** של המסך — מעבר מסלול
- **נגיעה באמצע** — קפיצה
- **החלקה** לכל כיוון עובדת גם היא (למעלה = קפיצה, למטה = החלקה מתחת למוט)
- אוספים ⭐ כוכבים, 💎 יהלומים (5 כוכבים), 🧲 מגנט ו-🫧 בועת הגנה
- כל 25 כוכבים — חגיגת קונפטי
- הכוכבים הם ניקוד לחגיגה בלבד. הם לא נועלים כלום

## איכות תצוגה

| מצב | מה קורה |
|---|---|
| רגיל | עד פי 2 מהרזולוציה הלוגית — הכי חסכוני בסוללה |
| גבוה (ברירת מחדל) | **הרזולוציה הפיזית המלאה של המסך** (DPR 3 באייפון) |
| מקסימלי | מצייר בערך פי 1.35 *מעל* הרזולוציה הפיזית ומקטין — דגימת־על שמחליקה קצוות |

נקודה חשובה: "8K" הוא מונח של מסכי טלוויזיה. מסך אייפון הוא בערך 1179×2556
פיקסלים פיזיים, ואי אפשר להציג עליו יותר מזה — מה שכן אפשר, וזה מה שהמצב
"מקסימלי" עושה, זה לצייר *מעל* הרזולוציה הזו ולהקטין, כך שהקצוות יוצאים חלקים
במיוחד. כל הגרפיקה וקטורית ומצוירת בזמן אמת, ולכן היא נשארת חדה בכל רזולוציה,
כולל על מסך חיצוני 4K או 8K דרך AirPlay.

בנוסף המשחק מודד לעצמו קצב פריימים: אם המכשיר יורד מתחת ל-40 FPS למשך יותר
משתי שניות, הרזולוציה יורדת בשקט עד שהתנועה חלקה שוב, ועולה בחזרה כשאפשר.

### מה עוד שופר בתמונה
- **אובך מרחק** — הרקע הרחוק נמסך לתוך צבע האופק, מה שנותן עומק אמיתי
- **אבני שפה** אדום־לבן לאורך הכביש, ושיפוע אור לרוחבו
- **נוף מגוון** — עצים, פנסים, שיחים, סלעים ופרחים בפיזור לא־מחזורי
- **זוהר** על הכוכבים והיהלומים, **ויניה** עדינה, ו**פסי מהירות** כשרצים מהר
- הצללה ומתאר על הדמויות, כדי שגם דמויות בהירות יבלטו על רקע בהיר

## מבנה הקוד

```
index.html              כל המסכים (DOM) + הקנבס
css/style.css           עיצוב הממשק, בטיחות ל-safe-area של האייפון
js/util.js              עזרים, פירוק צבעים, פרופילי שחקנים ושמירה ב-localStorage
js/audio.js             סינתזת צלילים ב-Web Audio + דיבור בעברית
js/characters.js        ציור פרוצדורלי של שתים־עשרה הדמויות
js/world.js             פרספקטיבה, שמיים משתנים, כביש, נוף, אובך, אביזרים
dist/                   קובץ HTML יחיד שנבנה מהמקור (tools/build_single.py)
js/game.js              לולאת המשחק, קלט, יצירת מסלול, התנגשויות
js/main.js              חיבור המסכים למשחק
sw.js                   Service Worker — עבודה אופליין
tools/make_icons.py     יצירת אייקוני PNG בלי תלויות
```

אין תלויות ואין node_modules. קובץ HTML אחד ושישה מודולי ES.
כל הגרפיקה מצוירת ב-Canvas בזמן אמת, ולכן חדה בכל רזולוציה ומשקלה אפס.

### להוסיף דמות חדשה
מוסיפים רשומה ל-`CHARACTERS` ב-`js/characters.js` (מזהה, שם, צבעי פרווה)
ומטפלים במקרה שלה ב-`drawHead`. הבורר, מסך הבית והמשחק מתעדכנים לבד.

### לשנות את קצב המכשולים
`SLOT_GAP` ב-`js/game.js` (מרווח בין "משבצות" מסלול) ופרופילי `SPEEDS`
ב-`js/util.js`.

## פרטיות

אין שרת, אין אנליטיקס, אין רשת. כל מה שנשמר יושב ב-`localStorage`
של המכשיר בלבד: שמות השחקנים, הצבעים, הכוכבים והדמויות. "איפוס מלא" בהגדרות
ההורים מוחק הכל.
